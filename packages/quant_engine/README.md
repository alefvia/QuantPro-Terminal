# Quant Engine

Responsável por features, baselines estatísticos, ML, ensembles e calibração.

Regras:
1. benchmark simples antes de modelo complexo;
2. separação temporal de treino/validação/teste;
3. probabilidade somente após calibração;
4. custo/slippage entram na avaliação;
5. nenhum modelo pode liberar execução Live.
